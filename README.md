## Petroleum Logistics and Inventory Management System

My name is Goodluck Aberare, and I am an aspiring software engineer passionate about developing my programming and problem-solving skills.

As part of my journey toward becoming a skilled software developer, I developed this Petroleum Logistics and Inventory Management System to strengthen my understanding of Python programming, database management, and the development of practical software applications. The project focuses on solving basic inventory and delivery management challenges within the petroleum logistics industry.

## Software Description

This software is a simple Python-based Petroleum Logistics and Inventory Management System designed to manage petroleum products, truck records, deliveries, and financial transactions.

The application uses Python's built-in SQLite database to store and manage information. It allows users to add petroleum products, register trucks and drivers, record deliveries, monitor available inventory, generate delivery reports, and view financial summaries.

The system uses important programming and database concepts, including functions, conditional statements, loops, exception handling, SQL queries, database tables, primary keys, foreign keys, and table relationships.

## Purpose

My purpose for creating this software is to gain practical experience in software development while applying programming and database management concepts to a real-world business problem.  The petroleum logistics industry involves managing large quantities of products, transportation activities, deliveries, and financial records. Through this project, I aim to develop a basic system that makes it easier to manage petroleum inventory, monitor truck deliveries, and maintain transaction records. I also hope to improve my understanding of relational databases, SQL operations, Python functions, and problem-solving techniques. This project is an important step in my journey toward becoming a skilled software developer capable of building applications that solve practical business and industry challenges.

## Key Features

- **Product Management:** Add petroleum products and record their quantities and unit prices.
- **Truck Management:** Register trucks and their corresponding drivers.
- **Delivery Management:** Record petroleum deliveries, destinations, quantities, and delivery dates.
- **Inventory Tracking:** Monitor available petroleum stock and automatically update inventory after a delivery.
- **Delivery Reports:** Generate reports showing delivery details by connecting related database tables.
- **Financial Reports:** View summaries of recorded delivery transactions.
- **Database Management:** Store and organize information using SQLite relational database tables.

## How to Run the Program

1. Ensure Python is installed on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in VS Code.
4. Run the following command:

   `python petroleum_management.py`

5. Follow the menu options displayed on the screen to interact with the system.

The SQLite database file, `petroleum_logistics.db`, is created automatically when the program runs.
